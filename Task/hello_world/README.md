# Hello World HTML Project

A simple HTML project that displays **"Hello World!"** on a webpage.

## 📁 Project Structure

```text
project-folder/
│
├── index.html
└── README.md
```

## 💻 Code

The `index.html` file contains:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Hello World</title>
</head>
<body>

    <h1>Hello World!</h1>
 

</body>
</html>



```

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. You will see:

**Hello World!**

## 🛠️ Technologies Used

* HTML5

## 📌 Purpose

This project is a basic introduction to HTML as Task 1.
