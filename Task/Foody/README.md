# 🍴 Food Project

A modern and responsive **Healthy Food Landing Page** built using **HTML5 and CSS3**.

The project presents a clean food-service website with sections for food delivery, features, meal gallery, app information, available cities, customer testimonials, pricing plans, contact form, and social links.

---

## 📌 Project Overview

The **Food Project** is a frontend website designed for a healthy food delivery service.

The website focuses on:

- Healthy food delivery
- Meal showcase
- Subscription/pricing plans
- Customer testimonials
- App download promotion
- City/service information
- Contact form
- Responsive design

The main page is implemented in `index.html` and uses separate CSS files for styling and responsive layouts.

The **How It Works** section explains the process in three steps:

1. Choose a suitable plan and sign up.
2. Pay for the plan and download the app.
3. Start ordering food.

It also includes Google Play and Apple App Store buttons.

## 🚀 How to Run the Project

### 1. Clone or Download the Project

Download the project to your computer.

### 2. Open the Project

Open the project folder in **VS Code** or another code editor.

### 3. Run the Website

You can open `index.html` using:

- VS Code Live Server
- Any local development server
- A web browser

### Recommended

If you have the **Live Server** extension installed in VS Code:

```text
Right-click index.html
        ↓
Open with Live Server
```
