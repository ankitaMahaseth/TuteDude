# Laundry Services Hero Section

A simple and responsive **Laundry Services Hero Section** built using **HTML and CSS**.
This project demonstrates a clean navigation bar and a two-column hero section with a call-to-action button and laundry-related image.

## 📸 Preview

The webpage contains:

- Logo section
- Navigation menu
- Username button
- Hero heading
- Laundry services description
- "Book a service today!" call-to-action button
- Laundry service image
- Responsive layout for smaller screens

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Design

## 📁 Project Structure

```text
laundry-services/
│
├── index.html
├── style.css
│
└── images/
    └── laundry_img.jpg
```

## 🚀 How to Run

1. Clone or download this repository.

2. Open the project folder.

3. Make sure the laundry image is located at:

```text
images/laundry_img.jpg
```

4. Open `index.html` in your web browser.

That's it! No additional dependencies or installations are required.
