# My English World Website

A responsive website for **My English World**, an English language and
communication skills training platform. The website introduces the
organization, highlights its training programs, presents the founder and
trainer, and provides contact information.

## Features

-   **Homepage / Hero section** introducing My English World.
-   **About section** describing the training philosophy and experience.
-   **Services section** highlighting children's workshops, adult
    workshops, Jolly Learning Suite, handwriting, calligraphy,
    short-term courses, and post-course support.
-   **Team section** presenting the founder and trainer.
-   **Contact section** with a contact form layout.
-   **Footer** with contact details, social media links, quick
    navigation links, and a newsletter signup layout.
-   **Copyright section** with website attribution.
-   **Responsive layout** built with Bootstrap utility and grid classes.
-   **Animations and icons** using the included animation library and
    Font Awesome / Bootstrap Icons.

## Technologies Used

-   Bootstrap 5

## Getting Started

1.  Download or clone the project.
2.  Keep the `index.html`, `css`, `js`, `img`, and `lib` folders in the
    expected locations.
3.  Check that the referenced image and library files exist.
4.  Open `index.html` in a browser, or use the **Live Server** extension
    in Visual Studio Code for local development.

## Main Sections

### Navigation

The navigation menu links to the Home, About Us, Our Services, Blogs,
and Contact Us sections or pages.

### About Us

Introduces My English World and its focus on building skills and
confidence through English-language training.

### Our Services

Lists training offerings, including: - Children's workshops - Adult
workshops - Jolly Learning Suite - Handwriting programme - Calligraphy -
Short-term courses for children and adults - Post-course support

### Team

Introduces **Sirisha Ravi**, Founder & Trainer, and lists professional
qualifications and experience as provided in the website content.

### Contact

Displays a contact form layout for name, email, mobile number, subject,
and message.

### Footer

Contains the organization logo, tagline, address, phone number, email
address, social media icons, quick links, and newsletter signup layout.

## Configuration and Customization

-   **Text and content:** Edit the relevant sections in `index.html`.
-   **Styling:** Update `css/style.css`.
-   **JavaScript behavior:** Update `js/main.js`.
-   **Images and favicon:** Replace files in `img/` while keeping
    filenames or updating their paths in the HTML.
-   **Navigation:** Replace placeholder links such as `href="#"` with
    real page or profile URLs.

## Important Notes

-   The contact form is a front-end layout unless connected to a backend
    or form-handling service.
-   The newsletter signup requires a backend or newsletter service to
    store subscriptions.
-   Social media links should be updated with the organization's real
    profile URLs.
-   Confirm that all local images, CSS, JavaScript, and library paths
    exist before deployment.
-   External Google Fonts, Font Awesome, and other CDN resources require
    an internet connection.
