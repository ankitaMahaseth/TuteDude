# Laundry Wallah / Laundry Mart

A simple HTML-based laundry service webpage for **Laundry Wallah / Laundry Mart**. The website provides information about laundry services, pricing, and a basic booking form for customers.

## 📌 Features

* Welcome section introducing Laundry Wallah / Laundry Mart
* Laundry-related image
* List of available services
* Sample of  price list
* Basic booking form
* Contact email information

## 🛠️ Technologies Used

* **HTML5**
* Basic HTML forms
* HTML tables
* HTML lists
* Image elements

## 📂 Project Structure

```text
Laundry-Mart/
│
├── index.html
├── README.md
│
└── images/
    └── laundry_img.jpg
```

## 🚀 How to Run

1. Download or clone this project.
2. Make sure the `laundry_img.jpg` file is present inside the `images` folder.
3. Open `index.html` in any modern web browser.

No additional software, libraries, or dependencies are required.
